Restore

Put this server back to the state captured in a backup. This replaces the current database, attachments and media. Your current data is copied aside first, but getting it back is a command-line step, so treat this as one-way.
{% include 'core/partials/restore_status.html' %}

Software updates

Update Murphy's Bench to the latest release without the command line. The update backs up first, applies the new version, restarts, and automatically rolls back (code and database) if anything fails. It runs in the background; this page keeps you posted.
